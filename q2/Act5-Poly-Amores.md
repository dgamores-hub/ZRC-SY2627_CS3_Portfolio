ACTIVITY 5

1. What do all the methods (move(), special_move(), use()) in the previous activities have in common?
- They all have the same method names but do different things depending on the object using them.

2. How does this activity show polymorphism in a gaming context?
- It shows polymorphism because different characters and items can use the same
method name but perform different actions. 

3. Can you think of other examples where the same action behaves differently depending on the character
or item?
- Attack: A warrior uses a sword, while a mage casts a spell.
- Heal: A healing potion restores health, while a healer character uses a healing skill.
- Defend: A warrior blocks with a shield, while an archer dodges an attack.
